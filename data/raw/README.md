# Raw Data

This directory stores the original input datasets used for calculating the Surface Urban Heat Island (SUHI) index in Vietnam for 2025.

---

## 📁 Directory Structure & Files

### 📂 Subdirectories
* **`GHS-SMOD/`**: Contains raw Global Human Settlement Layer (GHS-SMOD) datasets used for urban and rural area classification.
* **`HUMDATA/`**: Contains Vietnam administrative boundary shapefiles/spatial data downloaded from HDX.
* **`MYD11A2/`**: Contains MODIS Aqua Land Surface Temperature (LST) 8-day 1km datasets and Google Earth Engine (GEE) export scripts.

### 📄 Clipped GeoTIFF Files
* **`GHS_SMOD_clipped_vn.tif`**: Urban/rural settlement classification raster clipped to Vietnam's national boundary.
* **`MYD11A2_A2025_clipped_vn.tif`**: Land Surface Temperature (LST) 2025 raster series clipped to Vietnam's national boundary.

# Raw Data

This directory contains the original input datasets used to calculate the Surface Urban Heat Island (SUHI) over Vietnam for 2025.

---

## Directory Structure

### GHS-SMOD/

Contains the Global Human Settlement Layer (GHS-SMOD) datasets used for urban and rural classification.

### HUMDATA/

Contains Vietnam administrative boundary datasets downloaded from the Humanitarian Data Exchange (HDX).

### MYD11A2/

Contains MODIS Aqua Land Surface Temperature (LST) datasets and the Google Earth Engine (GEE) export script.

---

## Clipped Raster Files

### GHS_SMOD_clipped_vn.tif

GHS-SMOD raster clipped to the Vietnam national boundary.

### MYD11A2_A2025_clipped_vn.tif

Median MODIS MYD11A2 Land Surface Temperature (LST) raster for April–August 2025, clipped to the Vietnam national boundary.
