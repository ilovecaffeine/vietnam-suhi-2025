# Figures

This directory contains figures automatically generated by the SUHI analysis workflow.

All figures can be reproduced by running the analysis scripts in `src/`.

---

## Files

### `suhi_histogram.png`
Histogram showing the distribution of Surface Urban Heat Island (SUHI) intensity across all urban zones.

### `suhi_vs_area_scatter.png`
Scatter plot showing the relationship between urban area and SUHI intensity, including the Spearman correlation coefficient.

### `moran_scatter.png`
Global Moran scatter plot illustrating the spatial autocorrelation of SUHI values.
